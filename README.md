# 50-DSA-Questions

50 essential Data Structures and Algorithms interview questions with solutions in Python and C++.

> Source material lives in `50-DSA-Questions-main/` (original extracted archive). See that folder's `README.md` for the full question table.

## Contents
- Arrays, Strings, Linked Lists, Trees, Graphs, DP, and more
- Each problem: `solution.py` + `solution.cpp`

## Getting Started
No build step required. Browse solutions directly:

```bash
ls 50-DSA-Questions-main/Arrays
python 50-DSA-Questions-main/Arrays/01_TwoSum/solution.py
```

## Tech
- Python 3, C++17
